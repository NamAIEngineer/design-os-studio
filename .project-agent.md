# DESIGN:OS Studio (`design-os-studio`)

## Product Identity
- **Name**: DESIGN:OS Studio (`design-os-studio` — `https://github.com/jangtrinh/design-os-studio`)
- **Role**: Native GPU-accelerated Rust design canvas, `.fig` / `.designos` editor, and headless MCP server (`designos-mcp`) for the **DESIGN:OS / EaseUI** ecosystem.
- **Theme**: EaseUI BrainWave 2.0 Dark (`#121215` canvas, `#18181B` panels, `#27272A` surface/borders, `#E36323` BrainWave orange brand accent, `#3582FF` canvas blue selection, `#8755E9` component violet).

## Tech Stack
- **Language**: Rust (`edition = "2021"`, `rustc 1.93.1`)
- **UI & Windowing**: `egui 0.31` + `eframe 0.31` (`wgpu` Metal backend on macOS)
- **GPU Renderer**: `crates/designos-gpu` (`wgpu 24`, custom WGSL shaders + `lyon` tessellation)
- **CPU Renderer / Tile Cache**: `crates/designos-render` (`tiny-skia 0.11`, `SceneIndex`, `TileCache`)
- **Document Model**: `crates/designos-doc`
- **Figma `.fig` Importer/Exporter**: `crates/designos-fig` (Kiwi binary format + REST JSON + SVG/PDF)
- **Projects Library**: `crates/designos-library`
- **MCP Server**: `crates/designos-mcp` (`designos-mcp` & `designos-mcp` stdio JSON-RPC)

## Verification Commands
Always prepend `$HOME/.cargo/bin` to `PATH`:
```bash
export PATH="$HOME/.cargo/bin:$PATH"
cargo test --workspace --lib
cargo test -p designos-gpu
cargo test -p designos-mcp
cargo build --release -p designos-app -p designos-mcp
```
