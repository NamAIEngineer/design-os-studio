design:os studio — install and first launch
===========================================

1. Drag designos.app into the Applications folder.
2. Double-click install-cli.command (optional) to clear the macOS quarantine
   flag and symlink the 4 CLI tools onto your PATH (~/.local/bin or /usr/local/bin):
     - designos-studio  (GUI studio app)
     - designos         (GUI + headless CLI / renderer / exporter)
     - designos-mcp     (MCP server for Claude Code, Codex, Antigravity)
     - designos-diff    (visual & .fig diff CLI tool)
3. Open Applications and launch designos.

First-launch Gatekeeper note
----------------------------
If you launch designos.app before running install-cli.command, macOS may ask
you to confirm because the build is ad-hoc signed rather than Apple Developer ID
notarized. Either run in Terminal:

    xattr -dr com.apple.quarantine /Applications/designos.app

or go to System Settings -> Privacy & Security -> scroll down to "designos" ->
click "Open Anyway".

Command-line & MCP tools
------------------------
All 4 binaries live inside /Applications/designos.app/Contents/MacOS/:

    /Applications/designos.app/Contents/MacOS/designos --help
    /Applications/designos.app/Contents/MacOS/designos-mcp --help
    /Applications/designos.app/Contents/MacOS/designos-diff --help
