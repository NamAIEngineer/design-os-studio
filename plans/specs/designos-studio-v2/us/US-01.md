## 1. User Story
Là **Product Designer & UI Architect**, tôi muốn mở/ghi trực tiếp file `.fig` nhị phân chuẩn v106 và sử dụng bố cục 2D CSS Grid (`fr`, `px`, `auto`, `col_span`, `row_span`), để làm việc 1:1 với hệ sinh thái Figma và xuất/nhập bản thiết kế `.spec.json` không mất dữ liệu.

## 2. Flow
- Điều kiện bắt đầu: Người dùng đang mở tài liệu trên màn hình Canvas `S01` hoặc chọn một gói Spec trong `S02`.
- Luồng chính: 1. Mở hoặc nhập file `.fig` v106 / `.spec.json`. 2. Chọn Frame và bật `LayoutDirection::Grid` với cấu hình cột/hàng `1fr 2fr` hoặc `px`. 3. Nhấn **Save .fig** hoặc **Export .spec.json** để lưu lại kết quả lossless.

## 3. Dữ liệu và quy tắc

| ID | Quy tắc | Nguồn |
|---|---|---|
| **BR-01** | Mọi trường nhị phân không xác định trong Kiwi container v106 phải được giữ nguyên trong `raw_fields` khi round-trip `.fig`. | [contract](../contract/FC-001.md) D1 |
| **BR-05** | Mọi Frame trên Canvas có thể xuất sang `.spec.json` (`NodeSpec`) hoặc áp dụng ngược từ `.spec.json` vào trang đang mở bằng 1 lệnh undoable. | [contract](../contract/FC-001.md) D5 |

## 4. Acceptance Criteria

| ID | Given | When | Then | Scenario |
|---|---|---|---|---|
| AC-01 | File `.fig` chuẩn v106 có chứa node Auto-Layout và trường mở rộng | Người dùng mở và lưu lại file `.fig` | Toàn bộ cây node, biến màu và `raw_fields` được bảo toàn 100% không mất byte dữ liệu. | SCN-01-01 |
| AC-02 | Một Frame đang bật chế độ `LayoutDirection::Grid` với các cột `1fr`, `2fr` và child có `col_span = 2` | Hệ thống tính toán bố cục `relayout_subtree` | Các ô con được căn chỉnh chính xác theo lưới 2 chiều, hỗ trợ khoảng cách cột/hàng và span nhiều ô. | SCN-01-02 |
| AC-03 | Gói Spec đang mở có bản thiết kế khai báo `.spec.json` | Người dùng nhấn `Apply Spec to Canvas` | Cây `NodeSpec` được dựng thành Frame thật trên Canvas và tự động zoom vừa khung nhìn. | SCN-01-03 |

## 5. Edge cases
- Rỗng (`empty`): Khi trang Canvas chưa có Frame nào, hiển thị hướng dẫn 1 hành động `Apply Spec to Canvas` hoặc tạo Frame mới.
- Lỗi (`error`): Khi file `.spec.json` hoặc `.fig` bị hỏng cấu trúc, hiển thị thông báo toast nêu rõ lỗi giải mã và giữ nguyên trạng thái tài liệu hiện tại.
- Đang tải (`loading`): Hiển thị tiến trình nạp chunk Kiwi khi mở file `.fig` lớn.
