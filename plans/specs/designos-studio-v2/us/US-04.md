## 1. User Story
Là **Product Designer & Team Lead**, tôi muốn quản lý toàn bộ tài liệu thiết kế tại màn hình Home chuẩn Figma UI3 (`S04`) với các phân mục `Recents`, `Drafts`, `All folders`, `Resources / Templates`, `Starred`, `Trash`, bộ lọc loại file, sắp xếp, chuyển đổi Grid/List, huy hiệu loại file và menu ngữ cảnh chuột phải, để tổ chức dự án `.fig` và `.spec.json` giống hệt Figma Desktop.

## 2. Flow
- Điều kiện bắt đầu: Người dùng nhấn biểu tượng Home ở góc trên bên trái hoặc khởi động Studio vào chế độ File Browser (`S04`).
- Luồng chính: 1. Chọn phân mục điều hướng bên trái (`Recents`, `Drafts`, `All folders`, `Resources`, `Starred`, `Trash`). 2. Tìm kiếm theo tên, lọc theo loại (`Design`, `FigJam`, `Slides`, `Spec v2`) hoặc đổi thứ tự sắp xếp (`Last modified`, `Alphabetical`, `Date created`). 3. Nhấp đúp vào thẻ file để mở trên Canvas hoặc nhấp chuột phải để `Duplicate`, `Rename`, `Star`, `Export .fig`, `Move to Trash` / `Restore`.

## 5. Edge cases
- Rỗng (`empty`): Khi phân mục `Starred` hoặc `Trash` chưa có tài liệu nào, hiển thị thẻ trạng thái trống kèm nút hành động `+ New Design File` hoặc `Import .fig`.
- Lỗi (`error`): Khi người dùng nhập file `.fig` bị hỏng từ nút `Import`, hiển thị banner báo lỗi giải mã ngay trên đầu màn hình Home mà không làm mất danh sách file hiện có.
- Đang tải (`loading`): Hiển thị khung xương (`skeleton thumbnail`) trong khi kết xuất ảnh thu nhỏ cho file `.fig` lớn.
