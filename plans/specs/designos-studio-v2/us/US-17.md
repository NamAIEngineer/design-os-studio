# US-17: 1:1 Figma Micro-Interactions, Keyboard Stepping, Scrubbing & Direct Manipulation

## 1. User Story

**As a** Product Designer or Design Engineer working in `design:os studio`,
**I want** every numeric field, color input, on-canvas shape/Auto-Layout handle, spatial guide, keyboard shortcut, and layer row to respond with 1:1 Figma Desktop `126.9.13` micro-interaction state machines (`MI-01` .. `MI-20`),
**So that** muscle-memory workflows (`ArrowUp/Down` `±1`/`±10`/`±0.1`, infix & `Mixed` math expressions, prefix drag-scrubbing, per-channel Hex stepping, on-canvas Corner/Arc/Star/Auto-Layout handles, `Alt` distance guides, `0–9` rapid opacity, and `I` eyedropper loupe) execute at `< 1ms` with transactional `Escape` rollback.

## 2. Main Flow

- User clicks or tabs into any right-hand Inspector numeric input (`X`, `Y`, `W`, `H`, `R`, `∠`, `Opacity`, `Font Size`, `Padding`, `Gap`) and presses `ArrowUp` or `ArrowDown` (with optional `Shift` for `±10` or `Alt` for `±0.1`); the property steps live on the canvas while keeping the full text highlighted for rapid consecutive nudges (`MI-01`).
- User types a multi-operator arithmetic expression (`100+24*2`, `(320-32)/3`) or a relative operator (`+16`, `*1.5`, `/2`, `50%`) across a `Mixed` multi-selection and presses `Enter`; the Shunting-Yard evaluator updates every selected node proportionally (`MI-02`).
- User hovers a numeric field's prefix label (`W`, `H`, `X`, `Y`, `R`, `∠`), sees the horizontal resize cursor (`ew-resize`), and drags horizontally (with `Shift` `10×` or `Alt` `0.1×`) or scrolls `Alt + MouseWheel`; releasing commits a single coalesced undo entry, while pressing `Escape` mid-scrub reverts to `valueBeforePreview` (`MI-03`).
- User places the caret inside the `RR`, `GG`, or `BB` byte pair of a Hex color input and presses `ArrowUp`/`ArrowDown` (or types shorthand `f`, `80`, `f0a`, `0d99ff80`, or `"coral"`), stepping the individual RGB channel or expanding shorthand into canonical `#RRGGBB` (`MI-04`, `MI-05`).
- User drags on-canvas circular shape handles for Rectangle Corner Radius (`Alt+Drag` for single corner, `MI-06`), Ellipse Arc Sweep / Donut Ratio / Start Angle (`MI-07`), Polygon/Star Point Count (`3..60`) and Inner Ratio (`MI-08`), or Auto-Layout pink `#EC4899` Padding and Gap bars (`MI-09`, `MI-10`) with live floating pill readouts.
- User holds `Shift`, `Alt`, `Cmd/Ctrl` (ignore constraints on resize), or `Space` (translate origin while drawing/marqueeing or suppress auto-reparenting while dragging), uses `Alt` hover red `#F24822` distance guides (`MI-13`), types rapid 2-digit opacity (`4` then `5` -> `45%`, `00` -> `0%`, `MI-15`), or presses `I` to sample canvas colors with the zoomed Magnifier Loupe (`MI-19`).

## 3. Business Rules

| ID | Rule | Source |
|---|---|---|
| BR-01 | Every continuous drag or scrub gesture (`MI-03`, `MI-06..MI-12`) MUST snapshot `valueBeforePreview` / `EditScopeSnapshot` at gesture start, coalesce intermediate frames into a single Undo transaction on `PointerUp`, and immediately revert to the pre-gesture state if `Escape` is pressed before release. | `FGEditScopeSnapshot.cpp` · `ux/figma-micro-interactions-spec.md` |
| BR-02 | Numeric and color micro-interactions (`MI-01..MI-05`) MUST never panic or corrupt document state on invalid input (`100/0`, `NaN`, malformed hex); invalid expressions MUST cleanly roll back to the previous valid value on `Enter` or `Blur`. | `0c62c2fd-cb7ba5a41c48c85a.min.js` · `widgets/field.rs` |
| BR-03 | All 20 micro-interactions (`MI-01..MI-20`) MUST maintain `< 1.0ms` per-frame CPU overhead and zero heap allocations during idle pointer hover. | `FC-001` §3 · `ux/figma-micro-interactions-spec.md` Layer 3 |

## 5. Edge Cases

- **Division by zero or malformed math expression (`100/0`, `12++*3`):** Evaluator returns `None` and the field restores `valueBeforePreview` without mutating any node (`MI-02`).
- **`Escape` pressed mid-scrub or mid-handle drag:** `cancel_interaction` / field rollback immediately restores pre-gesture geometry/style and pushes zero entries to the Undo stack (`MI-03`, `MI-06..MI-12`).
- **Two-digit opacity timeout (`> 400ms` between digits):** Pressing `4`, waiting `500ms`, then pressing `5` applies `40%` followed by `50%` instead of `45%`; pressing `0` once sets `100%` while `00` within `400ms` sets `0%` (`MI-15`).
- **Corner radius dragged beyond half of shortest side:** Radius clamps strictly to `min(width, height) / 2.0` (`MI-06`).
