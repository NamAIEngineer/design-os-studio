## 1. User Story
Là **UI Designer & Frontend Engineer**, tôi muốn sử dụng toàn bộ hệ thống Chrome, Settings, Menus và Popovers chuẩn Figma UI3 (`S05..S08`) gồm hộp thoại `Type settings` 3 tab (`Basic | Details | Variable`), thanh `Actions (Cmd+K)` neo phía trên thanh công cụ đáy, menu `Zoom/View` có ô nhập `%`, `Color Picker` (`HEX/RGB/CSS/HSL/HSB`), `Scoped Variables Picker` và `Dev Mode (</>)` Box Model + sinh mã 5 ngôn ngữ, để tinh chỉnh thiết kế và bàn giao code chính xác 1:1.

## 2. Flow
- Điều kiện bắt đầu: Người dùng đang mở tài liệu trên Studio (`S01`) và mở các popover/menu tương ứng (`S05..S08`).
- Luồng chính: 1. Nhấn biểu tượng `⋯` trong mục Typography để mở `Type settings` (`Basic | Details | Variable`) (`S05`). 2. Nhấn nút `Actions (Cmd+K)` trên thanh công cụ đáy để mở hộp thoại `Cmd+K` neo dưới đáy (`S06`). 3. Nhấn `Zoom % ⌄` ở góc phải trên để nhập tỷ lệ zoom hoặc bật/tắt `Pixel grid`, `Rulers`, `Layout grids` (`S05`). 4. Mở `Color Picker` hoặc `Scoped Variables Picker` (`S08`) và chuyển sang `Dev Mode (</>)` (`S07`) để xem Box Model cùng code CSS/Tailwind/SwiftUI/Compose/React.

## 5. Edge cases
- Rỗng (`empty`): Khi tài liệu chưa có Variable nào khớp phạm vi (`matches_scope`), `Scoped Variables Picker` hiển thị thông báo trống kèm nút `+ Create Variable`.
- Lỗi (`error`): Khi người dùng nhập giá trị `%` zoom hoặc mã màu `HEX` không hợp lệ, ô nhập tự động khôi phục giá trị hợp lệ trước đó mà không gây lỗi dựng hình.
- Bị khóa (`disabled`): Các tùy chọn `Type settings` tự động khóa khi node đang chọn không chứa văn bản hoặc đang bị khóa (`locked = true`).
