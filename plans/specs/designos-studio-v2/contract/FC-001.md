## 1. Outcome

Người dùng mở **`design`:os studio** có thể quản lý dự án tại màn hình Home chuẩn Figma UI3 (`S04`), mở và chuyển đổi tức thì giữa nhiều tab dự án song song trên thanh **Desktop Tab Strip (`36px`, `S10`)** với trạng thái hoàn toàn độc lập, thiết kế trực tiếp trên Canvas `.fig` v106 chuẩn 1:1 với 17 loại node và lưới 2D CSS Grid (`S01`), sử dụng đầy đủ các hộp thoại Typography 3-tab, Actions `Cmd+K`, Zoom/View, Color/Variables Picker và Dev Mode (`S05..S08`), làm việc với bảng **`Agents` Left Side Panel (`S13`, `DIR-17`, `DIR-21`)** dưới dạng giao diện Chat UI native bao trực tiếp lên trên PTY terminal shell sống của `Claude Code (claude)`, `Codex (codex)`, `Antigravity CLI (agy)` cùng 6 tác vụ Figma AI kèm `<50ms` Live Hot-Apply (`S11`, `S03`), đọc/duyệt toàn bộ gói Spec Format v2 theo 5 vai trò cùng bảng điểm **5-Pillar Quantitative Figma Parity Meter (`S02`, `S12`)**, cài đặt dễ dàng trên cả 3 hệ điều hành `macOS` (`.dmg`/`.app`), `Windows` (`-setup.exe`/`install.ps1`) và `Linux` (`.deb`/`install.sh`) (`DIR-22`) cũng như nhận bản cập nhật tự động an toàn qua Dual-Layer Auto-Update (`S09`), trải nghiệm hệ thống biểu tượng **Phosphor Icons đồng nhất 100% (`https://phosphoricons.com/`, `DIR-19`, `US-14`)**, và chạy xác minh ảnh chụp hoàn toàn ở chế độ nền (`with_active(false)`).
