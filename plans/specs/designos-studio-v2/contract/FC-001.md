## 1. Outcome

Người dùng mở **`design`:os studio** có thể quản lý dự án tại màn hình Home chuẩn Figma UI3 (`S04`), mở và chuyển đổi tức thì giữa nhiều tab dự án song song trên thanh **Desktop Tab Strip (`36px`, `S10`)** với trạng thái hoàn toàn độc lập, thiết kế trực tiếp trên Canvas `.fig` v106 chuẩn 1:1 với 17 loại node và lưới 2D CSS Grid (`S01`), sử dụng đầy đủ các hộp thoại Typography 3-tab, Actions `Cmd+K`, Zoom/View, Color/Variables Picker và Dev Mode (`S05..S08`), đọc/duyệt toàn bộ gói Spec Format v2 theo 5 vai trò (`S02`), thực thi lệnh AI Agent trong PTY Terminal tích hợp (`S03`), nhận bản cập nhật tự động an toàn qua Dual-Layer Auto-Update (`S09`), và chạy xác minh ảnh chụp hoàn toàn ở chế độ nền (`with_active(false)`).
