#### `canvas.fig` Binary Framing (v106)
1. **Header (`12` bytes)**:
   - Bytes `0..8`: ASCII magic `"fig-kiwi"` (or `"fig-jam."` for FigJam boards).
   - Bytes `8..12`: Little-endian `u32` container version = **`106`**.
2. **Chunk 0 — Schema (`75,231` B compressed $\rightarrow$ `195,763` B uncompressed)**:
   - Framed by `u32_le` byte length (`75,231`), compressed with **raw DEFLATE** (`flate2::read::DeflateDecoder`).
   - Encodes **`653` Kiwi definitions**: **`213` `ENUM`**, **`30` `STRUCT`**, **`410` `MESSAGE`**.
   - Root message is `Message` (`type_id = 354`, `39` fields); primary scenegraph payload is `Message.nodeChanges: NodeChange[]` (`NodeChange` `type_id = 250`, **`616` defined fields**) and `Message.blobs: Blob[]` (`Blob` `type_id = 235`).
3. **Chunk 1 — Scenegraph Message (`194,368,781` B compressed $\rightarrow$ `766,010,366` B uncompressed)**:
   - Framed by `u32_le` byte length (`194,368,781`), compressed with **Zstandard (`zstd`)** (`\x28\xb5\x2f\xfd`).
   - Unpacks to **`155,297` `NodeChange` records** and **`28,961` binary `Blob` records** (`commands`, `vectorNetworkBlob`, `styleOverrideTable` payloads).
